# 客户 Logo 素材

这些本地 SVG 保留品牌轮廓，转换为 Three.js 挤出几何，统一使用灯球的青绿色发光材质。网页运行时不请求品牌网站或 AI API。

- 安踏：官网 SVG，https://img.fishfay.com/theme/images/logo/logo-anta-r-02.svg
- 首钢园：用户提供的 `首钢园LOGO（彩色）.png`，保留放射符号与原版中英文轮廓。
- 美的：官网白色标识，https://web-res.midea.com/content/dam/midea-aem/global/official/midea-logo.png/jcr:content/renditions/midea-logo.webp
- 斐乐：官网标识，https://img01.fila.cn/theme_fl/images/logo/fila_blue_220321.png
- 迪桑特：官网三箭头标识，https://www.descente.co.jp/new/img/base/DESlogo.jpg
- 可隆：官网完整标识，https://images3.kolonmall.com/upload/content/e34f8f2b-52cb-4ac5-83a3-3bdbcd7d464b/kolonsport_logo.webp

位图素材按透明度或前景颜色提取闭合轮廓并保留孔洞，不重新设计字形。原色仅在全息投影材质中统一；源文件不受修改。
